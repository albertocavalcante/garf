# Packages

This directory contains the core packages of the project, each designed with a specific purpose following the "less is more" principle.

## Available Packages

- [core](core) - Core functionality and essential components
- [processor](processor) - Processing logic and data transformation
- [io](io) - Input/Output operations
- [progress](progress) - Progress tracking and reporting
- [mirror](mirror) - Mirroring and replication
- [destinations](destinations) - Destination handling
- [sources](sources) - Source handling
- [pointer](pointer) - Type-safe pointer utilities

For more detailed information about each package, please refer to their individual README.md files.
